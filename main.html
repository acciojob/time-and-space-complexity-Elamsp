Time, Space, Complexity

Time Complexity is efficient in a mathematical concept that measures how the execution time of an algorithm grows as the size of the input data increases. Instead of measuring actual runtime in seconds—which changes depending on hardware, operating system, and current computer load—time complexity counts the number of elementary operations a piece of code performs.

Space Complexity

Space complexity is the total amount of memory space an algorithm needs to run to completion relative to the size of its input. Just like time complexity measures how fast an algorithm runs, space complexity quantifies how "heavy" it is on the system's memory, typically expressed asymptotically using Big O notation O(n)
